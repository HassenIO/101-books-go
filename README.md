# 101 Go Books Book Merger

Download the free Go / Weiqi / Baduk problem booklets from [101books](https://101books.github.io/) and merge them into a single PDF with categories, continuous page numbers, and a clickable table of contents.

Source collection: **49 books**, **107 PDF volumes**, across **Tesuji**, **Tsumego**, and **Endgame**.

## Requirements

- Python 3.12+
- [uv](https://docs.astral.sh/uv/) (recommended) or pip

## Setup

```bash
uv sync
# or: python3 -m venv .venv && .venv/bin/pip install -e .
```

## Usage

### 1. Download the booklets

Fetches every PDF listed on the site into `docs/` and writes a structured catalog to `books.yaml`.

```bash
make download
# or: .venv/bin/python src/download_books.py
```

Existing files in `docs/` are skipped, so re-runs are safe.

### 2. Merge into one PDF

Builds `output/101-go-books.pdf`:

- Cover page
- Table of contents (with page numbers and clickable links)
- Category and book separator pages
- All booklet PDFs in catalog order
- Continuous page numbering across the whole volume
- PDF bookmarks for navigation

```bash
make merge
# or: .venv/bin/python src/merge_books.py
```

## Project layout

```
├── src/
│   ├── download_books.py   # scrape + download PDFs, write books.yaml
│   └── merge_books.py      # merge PDFs into one volume
├── docs/                   # downloaded PDFs (gitignored)
├── output/                 # merged PDF (gitignored)
├── books.yaml              # catalog: categories, ranks, parts, paths
├── Makefile
└── pyproject.toml
```

## Catalog (`books.yaml`)

Generated by the downloader. Structure:

```yaml
source: https://101books.github.io/
categories:
  - category: Tesuji
    books:
      - title: Specialized Training in Tesuji
        rank: 11k
        pdfs:
          - part: 1
            file: docs/specialized-training-in-tesuji-1.pdf
            url: https://101books.github.io/pdfs/...
```
