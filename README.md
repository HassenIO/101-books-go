# 101 Go Books Book Merger

Download the free Go / Weiqi / Baduk problem booklets from [101books](https://101books.github.io/) and merge them into a single PDF with categories, continuous page numbers, and a clickable table of contents.

Source collection: **49 books**, **107 PDF volumes**, across **Tesuji**, **Tsumego**, and **Endgame**.

## Requirements

- Python 3.12+
- [uv](https://docs.astral.sh/uv/) (recommended) or pip

## Setup

```bash
uv sync
# or: python3 -m venv .venv && .venv/bin/pip install -e .
```

## Usage

### 1. Download the booklets

Fetches every PDF listed on the site into `docs/` and writes a structured catalog to `books.yaml`.

```bash
make download
# or: .venv/bin/python src/download_books.py
```

Existing files in `docs/` are skipped, so re-runs are safe.

### 2. Merge into PDF volume(s)

Builds one PDF per entry under `outputs:` in `books.yaml` (written to `output/`).

Each volume includes:

- Cover page (uses the output title)
- Table of contents (page numbers + clickable links)
- Category and book separator pages
- Selected booklet PDFs
- Continuous page numbering and PDF bookmarks

```bash
make merge
# or: .venv/bin/python src/merge_books.py
```

## Catalog (`books.yaml`)

Generated by the downloader. Categories are scraped; `outputs` is preserved across re-downloads.

```yaml
source: https://101books.github.io/
categories:
  - category: Tesuji
    books:
      - title: Specialized Training in Tesuji
        rank: 11k
        pdfs:
          - part: 1
            file: docs/specialized-training-in-tesuji-1.pdf
            url: https://101books.github.io/pdfs/...

outputs:
  # No books list → every book in the catalog
  - title: "All 101 books"
  # books list → only those titles (must match category book titles)
  - title: "Road to Shodan: Tesujis"
    books:
      - "Specialized Training in Tesuji"
      - "Lee Chang-ho's Selected Tesuji"
```

Filenames are slugified from the title, e.g. `output/all-101-books.pdf`, `output/road-to-shodan-tesujis.pdf`.
